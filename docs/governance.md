# ธรรมาภิบาลข้อมูล ความปลอดภัย และค่าใช้จ่าย

## ข้อมูลส่วนบุคคล (PDPA)
- repo และเว็บเป็น**สาธารณะ** → ห้ามมีข้อมูลรายครัวเรือน/รายบุคคล (PPPConnext, พิกัดบ้าน 100 ครัวเรือน, ผู้ป่วยติดเตียง, เบอร์, LINE userId)
- เผยแพร่ได้: ข้อมูลรวมระดับหมู่บ้าน/วงระยะ, อาคาร Open Buildings (ไม่ผูกตัวบุคคล), ข้อมูลหน่วยงานสาธารณะ
- แผนที่รายครัวเรือน: **ตัดสินใจแล้ว (27 ก.ย. 69)** ใช้ Cloudflare Pages + Cloudflare Access เฉพาะผู้ดูแล ≤ 5 อีเมล
  ต้องทดสอบในหน้าต่างไม่ระบุตัวตนทุกครั้งที่เปลี่ยนค่า (หน้า, ไฟล์ .geojson, URL deployment ต้องถูกบล็อก)
  export จาก QGIS เฉพาะ field ที่จำเป็น — ห้ามมีชื่อ เลขบัตร เบอร์โทร
- ไม่ส่งไฟล์ข้อมูลครัวเรือนจริงให้ AI — พัฒนาด้วยข้อมูลสมมติที่มีโครงสร้างเดียวกัน
- ตรวจความยินยอมของครัวเรือน ข้อตกลง PPPConnext และการรับรองจริยธรรมการวิจัยก่อนใช้

## อำนาจการเตือนภัย
ระบบเป็น decision support สำหรับ ADM/อบต. · disclaimer อยู่ใน footer ทุกหน้าและในแถบแจ้งเตือน ·
ถ้อยคำใน LINE ต้องตกลงกับทีมและ ปภ. ก่อน · หน้า `/chanat/` เป็น mockup มีแถบเตือน "ข้อมูลสมมติ" ห้ามลบแถบจนกว่าจะเปลี่ยนเป็นข้อมูลจริง

## ความปลอดภัยของ key
- เก็บใน GitHub Secrets เท่านั้น · ห้ามใส่ในไฟล์ แชท screenshot
- ถ้าหลุด: ยกเลิกทันที → สร้างใหม่ → Update Secret → Run workflow
- เพิ่มผู้ร่วมดูแล repo อย่างน้อย 1 คน (Settings → Collaborators) และเปิด 2FA

## เงื่อนไขแหล่งข้อมูล (ต้องดำเนินการ)
| แหล่ง | สถานะ/สิ่งที่ต้องทำ |
|---|---|
| ThaiWater (สสน.) | ไม่มีเอกสาร API ทางการ → ทำหนังสือขอใช้ข้อมูลในนามโครงการ |
| GISTDA | ตรวจเงื่อนไขการแสดงผลสาธารณะของ API key |
| RainViewer / Open-Meteo | ฟรีสำหรับงานไม่ใช่เชิงพาณิชย์ ต้องแสดงเครดิต (ทำแล้ว) |
| Esri World Imagery (basemap) | เรียกแบบไม่มี key → ตรวจเงื่อนไข หรือเปลี่ยน basemap |
| Open Buildings | CC BY 4.0 / ODbL แสดงเครดิตแล้ว |
| ขอบเขตตำบล | OpenGISData-Thailand ไม่ระบุต้นฉบับ → แทนด้วยข้อมูลกรมการปกครอง |

## ค่าใช้จ่ายและข้อจำกัด GitHub (repo สาธารณะ = ฟรี)
- Pages ~1 GB, bandwidth soft ~100 GB/เดือน, build soft ~10 ครั้ง/ชม. — ใช้จริงน้อยกว่ามาก
- repo โตจาก commit รายชั่วโมง (~60 KB/รอบ) + ภาพ S1 1.6 MB ต่อภาพใหม่ → ประมาณ 200–350 MB/ปี ทบทวนทุกปี
  (ทางเลือก: เก็บข้อมูลสดใน branch แยกที่ไม่สะสมประวัติ, ลดขนาดภาพ S1)
- ถ้าเปลี่ยนเป็น private ต้องใช้แผนเสียเงินจึงเปิด Pages ได้ · โดเมน `*.nrru.ac.th` ขอจากมหาวิทยาลัยได้
